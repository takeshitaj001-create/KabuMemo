# ウォッチリスト機能（お気に入り形式の登録銘柄プルダウン）改修設計書

## 1. 概要

登録銘柄をウォッチリスト単位で管理し、プルダウンで表示を切り替える機能を追加する。

---

## 2. 基本方針

| 項目 | 決定内容 |
|---|---|
| リスト方式 | 独立ウォッチリスト方式（銘柄コードの参照リスト） |
| 重複 | 同一銘柄を複数リストに所属させることを許容 |
| デフォルトリスト | あり（初期リスト「マイリスト」、削除可） |
| 孤立銘柄 | 許容しない（追加時にリスト選択必須） |
| 削除挙動 | 2段階削除（リストから除外 → 必要なら完全削除） |
| ドロップダウン配置 | 共通ヘッダー（MainLayout.razor）のタイトル右 |
| 非表示ページ | Settings・StockDetail（Nav.Uri で判定） |

---

## 3. データ設計

### 3.1 新規モデル（Models/WatchList.cs）

```csharp
public class WatchList
{
    public string Id { get; set; } = Guid.NewGuid().ToString();
    public string Name { get; set; } = "";
    public List<string> StockCodes { get; set; } = [];
}
```

### 3.2 既存モデル

`StockItem` は変更なし。銘柄マスターデータとして全件管理する。

### 3.3 localStorage 構成

| キー | 内容 |
|---|---|
| `kabumemo_stocks`（既存） | 銘柄マスターデータ（全件） |
| `kabumemo_watchlists`（新規） | `WatchList[]` |
| `kabumemo_active_list`（新規） | 選択中リストの ID |

---

## 3.4 初回起動・既存データ移行

機能リリース後の初回起動時（`kabumemo_watchlists` が存在しない場合）に自動マイグレーションを実行する。

### マイグレーションフロー

```
初回起動検出（kabumemo_watchlists が null）
        ↓
「マイリスト」を自動生成
        ↓
既存の kabumemo_stocks の全銘柄コードを
「マイリスト」の StockCodes に登録
        ↓
kabumemo_watchlists・kabumemo_active_list を保存
```

### localStorage の変化

```
// マイグレーション前
kabumemo_stocks:     [7203, 6758, 9984, ...]  ← 変更なし
kabumemo_watchlists: null（存在しない）

// マイグレーション後
kabumemo_stocks:     [7203, 6758, 9984, ...]  ← 変更なし
kabumemo_watchlists: [{
    Id: "xxx",
    Name: "マイリスト",
    StockCodes: ["7203", "6758", "9984", ...]  ← 全件コピー
}]
kabumemo_active_list: "xxx"                   ← マイリストが選択中
```

### ユーザーが見る変化

| タイミング | 状態 |
|---|---|
| リリース前 | 全銘柄が一覧に表示されている |
| リリース後・初回起動 | ヘッダーに「マイリスト」が選択された状態で同じ銘柄が表示される |
| 操作感 | 見た目の変化なし。ヘッダーにドロップダウンが増えるだけ |

### データ安全性

- `kabumemo_stocks`（銘柄マスター）は一切書き換えない
- マイグレーションは `StockCodes` に銘柄コードを参照として追加するだけ
- マイグレーション失敗時も既存データは無傷

### 実装

- マイグレーションは `WatchListService.InitializeAsync()` で実装
- `MainLayout.razor` の `OnInitializedAsync` 内で呼び出す
- 既存銘柄が0件の場合も「マイリスト」は生成する（空リストとして）

---

## 5. データフロー

```
localStorage
  kabumemo_stocks       → StockService          → 銘柄マスター（全件）
  kabumemo_watchlists   → WatchListService       → リスト一覧
  kabumemo_active_list  → WatchListStateService  → 選択中リストID
                                  ↓ OnChange イベント
                         MainLayout.razor（ヘッダードロップダウン）
                           ↙                    ↘
                    Home.razor            Disclosures.razor
                 （stocks フィルタ）      （取得対象フィルタ）
```

---

## 6. 削除フロー

```
リストから「削除」ボタン押下
        ↓
他のリストにも存在する？
  ├ YES → 「このリストから除外しますか？」確認 → 除外のみ（マスター残る）
  └ NO  → 「削除するとデータも完全に消去されます」警告 → マスターごと削除
```

---

## 7. 銘柄追加フロー

```
「銘柄を追加」ボタン押下
        ↓
リストが0件？（全リスト削除済みの場合）
  ├ YES → 「先にリストを作成してください」→ Settings へ誘導
  └ NO  → 追加モーダルでリスト選択（現在選択中リストをデフォルト）
              ↓
           マスター（kabumemo_stocks）に追加
           選択リストの StockCodes に追加
```

> 初回起動時は「マイリスト」が自動生成されるため、通常はリスト0件にならない。
> ユーザーが全リストを手動削除した場合のみ Settings への誘導が表示される。

#### 変更点

| 変更箇所 | 内容 |
|---|---|
| `@inject` | `WatchListService`・`WatchListStateService` 追加 |

| `WatchState.OnChange` | 購読 → `StateHasChanged()` |
| `IDisposable` | イベント購読解除 |
| インポートモーダル | 追加先リスト選択をデータパターンの上に追加 |
| `OpenImportModal()` | リスト一覧ロード・選択中リストをデフォルト選択 |
| `ExecuteImport()` | マスター追加後、選択リストの `StockCodes` にも登録 |

#### ファイルからデータ登録モーダル（変更後）


> 初回起動時は「マイリスト」が自動生成されるため、この画面は通常表示されない。

#### 銘柄追加モーダル（追加先リストを追加）

```
┌──────────────────────────────┐
│ 銘柄を追加                   │
│ [名称で検索] [コードで追加]    │
│ ──────────────────────────── │
│ 銘柄コード: [      ] 名称検索  │
│ 銘柄名:    [            ]    │
│ 追加先:    [高配当       ▼]  │  ← 新規追加
│            [キャンセル] [追加] │
└──────────────────────────────┘
```

#### 削除モーダル（2段階）

```
// 他リストにも存在する場合
┌────────────────────────────────────┐
│ リストから除外                      │
│ 「7203」をこのリストから除外します。  │
│ ※他のリストのデータは残ります        │
│               [キャンセル] [除外する] │
└────────────────────────────────────┘

// 最後のリストの場合
┌────────────────────────────────────┐
│ ⚠ 銘柄を完全削除                   │
│ 「7203」はどのリストにも属さなく    │
│ なります。データも削除されます。     │
│           [キャンセル] [完全削除する] │
└────────────────────────────────────┘
```

#### 変更点

| 変更箇所 | 内容 |
|---|---|
| `@inject` | `WatchListStateService`・`WatchListService` 追加 |
| `OnInitializedAsync` | 全銘柄ロード後、選択中リストで `stocks` をフィルタ |
| `WatchState.OnChange` | リスト切替時に再フィルタ＋ `StateHasChanged()` |
| `AddStock()` | 選択リストの `StockCodes` に追加 |
| `DeleteStock()` | 他リスト存在チェック → モーダル分岐 |
| `MoveUp/MoveDown` | `StockCodes` の並び順操作に変更 |
| `empty-state` | リスト未作成 / リスト内銘柄0件 で表示内容を分岐 |
