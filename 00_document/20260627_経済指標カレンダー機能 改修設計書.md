# 経済指標カレンダー機能 改修設計書

## 1. 概要

経済指標カレンダーは新規画面を実装せず、外部サイト（みんかぶFX）へのリンクとして提供する。
NavMenu に外部リンクを追加し、タップで `https://fx.minkabu.jp/indicators` を新規タブで開く。

---

## 2. 基本方針

| 項目 | 決定内容 |
| --- | --- |
| 実装方式 | 外部リンク（新規タブで開く） |
| リンク先 | [https://fx.minkabu.jp/indicators](https://fx.minkabu.jp/indicators) |
| 新規ファイル | なし |
| ナビゲーション | NavMenu にリンク追加 |

---

## 3. 変更ファイル

| ファイル | 変更内容 |
| --- | --- |
| `Layout/NavMenu.razor` | ナビゲーション全面刷新（高度な操作 + 経済指標カレンダーリンクを統合） |
| `Layout/MainLayout.razor` | ヘッダー改修（⚙ボタン・IR情報一覧ボタン廃止、ハンバーガーボタン追加・NavMenu 組み込み） |

---

## 4. 詳細設計

---

### 4.1 NavMenu 刷新（`Layout/NavMenu.razor`）

#### 現状

NavMenu.razor は「Home」リンクのみで実質未使用。
MainLayout.razor の `<header>` にある「IR情報一覧」ボタンと「⚙ 高度な操作」ボタンが実際のナビゲーション役を担っていた。

#### 今回の変更方針

- ⚙ ボタン（高度な操作モーダル）を廃止し、NavMenu に移管
- 「IR情報一覧」ボタンも NavMenu に移管
- 経済指標カレンダーへの**外部リンク**を追加
- NavMenu をハンバーガーボタン（≡）でトグルするオーバーレイ型メニューとして実装

#### ヘッダー変更（Before / After）

```
// Before
┌──────────────────────────────────────────────────────────┐
│ 📈 株価メモ  [ウォッチリスト ▼]  [IR情報一覧]  [⚙]         │
└──────────────────────────────────────────────────────────┘

// After
┌──────────────────────────────────────────────────────────┐
│ [≡]  📈 株価メモ  [ウォッチリスト ▼]                        │
└──────────────────────────────────────────────────────────┘
```

#### NavMenu 展開時のレイアウト

```
┌────────────────────────┐
│ メニュー             ✕  │
│────────────────────────│
│ 🏠 ホーム              │
│ 📅 経済指標カレンダー   │  ← 外部リンク（新規タブ）
│ 📰 IR情報一覧          │  ← ヘッダーから移動
│────────────────────────│
│ 📁 ウォッチリスト管理    │  ← 高度な操作から移動
│ 📂 ファイルからデータ登録 │  ← 高度な操作から移動
│ 📋 銘柄データをCSVで編集 │  ← 高度な操作から移動
│ ☁  GitHub 共有設定     │  ← 高度な操作から移動
└────────────────────────┘
```

#### 経済指標カレンダーのリンク実装

```html
<a href="https://fx.minkabu.jp/indicators" target="_blank" rel="noopener noreferrer"
   class="nav-link" @onclick="Close">
    📅 経済指標カレンダー
</a>
```

- `target="_blank"` で新規タブ表示
- `rel="noopener noreferrer"` でセキュリティ対策
- リンク押下後は NavMenu を閉じる（`@onclick="Close"`）

#### NavMenu の実装方針

| 項目 | 内容 |
| --- | --- |
| 表示トリガー | MainLayout の `<header>` に追加するハンバーガーボタン（≡）|
| 閉じ方 | ✕ ボタン押下 / オーバーレイ背景タップ / リンク押下後 |
| CSV編集・ファイル登録 | 押下時に既存モーダルを起動（現 MainLayout のロジックをそのまま流用） |
| ウォッチリスト管理 | `Nav.NavigateTo("watchlists")` に遷移 |
| GitHub 共有設定 | `Nav.NavigateTo("settings")` に遷移 |
| ページ遷移後 | NavMenu を自動的に閉じる（`NavLink` の `@onclick` で Close） |

#### NavMenu.razor の状態変数

NavMenu 内でモーダルを起動する必要があるため、MainLayout との連携が必要。

```
方式: EventCallback を使い MainLayout → NavMenu にモーダル起動関数を渡す

MainLayout.razor
  ├ NavMenu に [OnCsvModalOpen] [OnImportModalOpen] を EventCallback として渡す
  └ NavMenu 側はそれを @onclick に紐付けるだけ
```

#### ShowDropdown の調整

NavMenu 内の項目は全ページから利用するため、現在 `ShowDropdown` で除外している `/settings`・`/watchlists`・`/stock/` についても NavMenu 自体は常に開けるようにする。ウォッチリストドロップダウンの表示制御（`ShowDropdown`）は現状維持。

### 4.2 MainLayout ヘッダー改修（`Layout/MainLayout.razor`）

#### 変更点

| 変更箇所 | 内容 |
| --- | --- |
| `<header>` | ハンバーガーボタン（≡）追加、IR情報一覧ボタン削除、⚙ボタン削除 |
| `<NavMenu>` | MainLayout に `<NavMenu>` コンポーネントを組み込み |
| `showSettingsModal` 関連 | ⚙モーダルのテンプレート・ロジックを削除 |
| CSV・ファイル登録モーダル | 引き続き MainLayout に残す（NavMenu から EventCallback 経由で起動） |
