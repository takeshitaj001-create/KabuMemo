# KabuMemo デプロイ手順書

## 概要

KabuMemo は以下の2コンポーネントで構成されており、それぞれ独立してデプロイする。

| コンポーネント | 技術 | ホスティング先 |
|---|---|---|
| フロントエンド（SPA） | Blazor WebAssembly (.NET 10) | GitHub Pages |
| API プロキシ | Cloudflare Worker | Cloudflare Workers |

---

## 前提条件

| 項目 | 確認方法 |
|---|---|
| .NET 10 SDK インストール済み | `dotnet --version` → `10.x.x` |
| Node.js / npm インストール済み | `node --version` |
| Wrangler CLI インストール済み | `worker\` フォルダ内で `npx wrangler --version` |
| Cloudflare アカウントのメール認証済み | Cloudflare ダッシュボードで確認 |
| GitHub リポジトリへのプッシュ権限あり | `git remote -v` で `origin` を確認 |

---

## Part 1 : Cloudflare Worker のデプロイ

### 1-1. Worker フォルダへ移動

```powershell
cd C:\Users\takes\source\repos\KabuMemo\worker
```

### 1-2. Cloudflare にログイン（初回のみ）

```powershell
npx wrangler login
```

ブラウザが開くので Cloudflare アカウントで認証する。

### 1-3. デプロイ実行

```powershell
npx wrangler deploy
```

成功すると以下のように表示される。

```
Uploaded kabumemo-proxy (x.xx sec)
Published kabumemo-proxy (x.xx sec)
  https://kabumemo-proxy.kabumemo.workers.dev
```

### 1-4. 動作確認

ブラウザまたは PowerShell で疎通確認する（`7203` は任意の銘柄コード）。

```powershell
Invoke-RestMethod "https://kabumemo-proxy.kabumemo.workers.dev/api/quote/7203"
```

`quoteResponse.result` に株価データが返れば正常。

## Part 2 : フロントエンド（GitHub Pages）のデプロイ

### 2-1. プロジェクトルートへ移動

```powershell
cd C:\Users\takes\source\repos\KabuMemo
```

### 2-2. `index.html` の `<base>` タグを GitHub Pages 用に変更

`wwwroot\index.html` の `<base href>` を以下に変更する。

```html
<!-- 変更前（ローカル開発用） -->
<base href="/" />

<!-- 変更後（GitHub Pages 用） -->
<base href="/KabuMemo/" />
```

> **注意:** ローカルで `dotnet run` する場合はこの値を `/` に戻す必要がある。

### 2-3. リリースビルド実行

```powershell
dotnet publish -c Release
```

出力先: `bin\Release\net10.0\publish\wwwroot\`

### 2-4. SPA ルーティング用に `404.html` を作成

GitHub Pages は存在しないパスへのアクセスを `404.html` にリダイレクトする。  
Blazor SPA のルーティングを機能させるため、`index.html` を `404.html` としてコピーする。

```powershell
Copy-Item "bin\Release\net10.0\publish\wwwroot\index.html" `
          "bin\Release\net10.0\publish\wwwroot\404.html" -Force
```

### 2-5. ビルド成果物を Git に反映

#### 方法A: ビルド成果物をリポジトリルートに直接配置する場合

GitHub Pages の Source を「master ブランチ / root」に設定している場合。

```powershell
# ビルド成果物をリポジトリルートにコピー
Copy-Item "bin\Release\net10.0\publish\wwwroot\*" "." -Recurse -Force

# 変更をコミット＆プッシュ
git add -A
git commit -m "deploy: release build"
git push origin master
```

#### 方法B: `gh-pages` ブランチに成果物を配置する場合（推奨）

GitHub Pages の Source を「gh-pages ブランチ / root」に設定している場合。

```powershell
# gh-pages ブランチが存在しない場合は作成
git checkout --orphan gh-pages
git reset --hard

# ビルド成果物をコピー
Copy-Item "bin\Release\net10.0\publish\wwwroot\*" "." -Recurse -Force

# コミット＆プッシュ
git add -A
git commit -m "deploy: release build"
git push origin gh-pages --force

# master ブランチに戻る
git checkout master
```

## Part 3 : GitHub Pages の設定（初回のみ）

1. GitHub リポジトリ（`https://github.com/takeshitaj001-create/KabuMemo`）を開く
2. **Settings** → **Pages** を開く
3. **Source** を以下のように設定する

| 項目 | 設定値 |
|---|---|
| Branch | `gh-pages`（または `master`） |
| Folder | `/ (root)` |

4. **Save** をクリック
5. 数分後、`https://takeshitaj001-create.github.io/KabuMemo/` でアクセス可能になる

## Part 4 : 動作確認

| 確認項目 | 確認方法 |
|---|---|
| トップページが表示される | `https://takeshitaj001-create.github.io/KabuMemo/` をブラウザで開く |
| 銘柄コードを直接 URL 入力しても表示される | `https://takeshitaj001-create.github.io/KabuMemo/stock/7203` を開く |
| 株価が取得できる | 個別銘柄画面で「🔄 更新」ボタンを押して株価が表示されることを確認 |
| 企業概要・決算予定日が取得できる | 企業概要カードの「🔄 更新」を押してデータが表示されることを確認 |

## トラブルシューティング

### Worker デプロイ時に `code: 10034` エラー

Cloudflare アカウントのメールアドレスが未認証。  
`https://dash.cloudflare.com/` にログインしてメール認証を完了させる。

### GitHub Pages にアクセスすると 404 になる

- `wwwroot\index.html` の `<base href="/KabuMemo/" />` が設定されているか確認
- `404.html` が `wwwroot` 直下にコピーされているか確認
- GitHub Pages の Settings で正しいブランチが選択されているか確認

### 株価・企業概要が取得できない

- Worker が正常にデプロイされているか `Part 1-4` の疎通確認を実施
- `Services\StockApiService.cs` の `ProxyBaseUrl` が本番 Worker の URL になっているか確認

```csharp
private const string ProxyBaseUrl = "https://kabumemo-proxy.kabumemo.workers.dev";
```
